# Pixel-Soluce
## Réalisé par DELAVIGNE Tom - GROUPE DEV

> Le but avec Pixel-Soluce est de pouvoir s'entraider lorsqu'on est bloqué dans un jeu vidéo ! Mais le tout sans se faire spoiler bêtement !

Ce site fonctionne avec un système de **S.O.S.** : l'utilisateur poste le nom du jeu et décrit sa situation. Les contributeurs peuvent ensuite l'aider en proposant des réponses structurées en **3 paliers de difficulté** (allant du simple indice jusqu'à la solution). 

Un système de recherche et de filtres permet aux joueurs bloqués sur un même jeu de trouver des solutions plus rapidement, et l'auteur du ticket peut ensuite marquer le sujet comme résolu.

* Projet développé avec les technos demandées dans le cadre du BUT 3 MMI.
